# Tapir user documentation

Tapir is a management system for community-supported agriculture organizations.
This documentation explains how to use and configure Tapir.

This documentation is split into two parts:

  1. Admin user documentation to setup and configure a running tapir instance -> `/docs/admins`
  2. Developer documentation for people who want to support the further (software) development of tapir -> `/docs/dev`

Compliance topics are collected separately:

  - EU Cyber Resilience Act (CRA) and its relation to the GDPR -> `/docs/cra`

!!! note
    The user documentation is being expanded. More guides will be added over time.
